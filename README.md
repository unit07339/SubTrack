# 🎯 하네스 + 루프 엔지니어링 기반 서버리스 웹 프로젝트

본 프로젝트는 **AI 에이전트의 자율적 문제 해결 능력**과 **신뢰성 높은 소프트웨어 엔지니어링 원칙**을 결합한 **하네스(Harness) + 루프 엔지니어링(Loop Engineering)** 방법론을 통해 개발되는 서버리스(Serverless) 웹 애플리케이션 프로젝트입니다.

---

## 📌 핵심 방법론 개요

```mermaid
flowchart LR
    subgraph Harness["🛡️ 하네스 (Harness Engine)"]
        H1["정적 분석<br/>(Lint & TypeCheck)"]
        H2["단위/통합 테스트<br/>(Unit & Integration)"]
        H3["서버리스 에뮬레이터<br/>(Local Simulation)"]
        H4["E2E / 계약 검증<br/>(Contract Verification)"]
    end

    subgraph Loop["🔄 루프 엔지니어링 (Agentic Loop)"]
        L1["1. 상태 확인<br/>(STATE / TASK)"] --> L2["2. 마이크로 태스크 선정<br/>(Single Atomic Task)"]
        L2 --> L3["3. 집중 구현<br/>(Minimal Code Edit)"]
        L3 --> L4["4. 하네스 검증<br/>(Self-Verification)"]
        L4 -->|실패 (Retry < 3)| L3
        L4 -->|성공| L5["5. 상태 영속화<br/>(Log & Commit)"]
        L5 --> L1
    end

    Loop <--> Harness
```

### 1. 하네스 (Harness)
- 에이전트가 변경한 코드를 즉각적이고 결정론적(Deterministic)으로 검증할 수 있는 **테스트 및 검증 프레임워크**입니다.
- 사람의 주관적 리뷰 없이도 기계적으로 PASS / FAIL을 판정할 수 있도록 로컬 서버리스 시뮬레이션, Mocking, 자동화된 단일 검증 스크립트를 제공합니다.

### 2. 루프 엔지니어링 (Loop Engineering)
- AI 에이전트가 복잡한 대형 요구사항을 **원자적 단위(Micro-Task)로 쪼개어** 끊임없이 `구현 ➔ 하네스 검증 ➔ 자가 수정 ➔ 상태 기록`을 반복하는 자율 개발 사이클입니다.
- 무한 루프, 환각(Hallucination), 컨텍스트 오염을 방지하기 위한 **서킷 브레이커(Circuit Breaker)**와 **컨텍스트 보존 규칙**이 적용됩니다.

## 🚀 빠른 시작 (Quick Start)

### 1단계: 사전 요구사항 확인
- Node.js (v18+ LTS 권장) 또는 Java/JVM (프로젝트 백엔드 엔진에 따라 설정)
- 패키지 관리자 및 Git

### 2단계: 하네스 환경 점검
에이전트 또는 개발자는 작업 시작 전 하네스가 정상 작동하는지 확인합니다:
```bash
# 전체 하네스 통합 검증 실행
npm run harness:verify
# 또는 설정된 하네스 테스트 스크립트 실행
```

### 3단계: 루프 사이클 시작
1. [`STATE.md`](./STATE.md)와 [`TASK.md`](./TASK.md)를 확인하여 가장 우선순위가 높은 미완료 태스크 1개를 선택합니다.
2. [`LOOP.md`](./LOOP.md)의 프로토콜에 따라 작업을 수행하고 하네스 통과 후 상태를 기록합니다.

## 🛡️ 에이전트 행동 지침 (Rule of Conduct)

1. **단일 작업 원칙 (Single Responsibility)**: 한 번의 루프에서 오직 1개의 마이크로 태스크만 수정합니다.
2. **하네스 무결성 (Harness-First)**: 하네스 통과 전에는 작업을 완료(`[x]`)로 표시할 수 없습니다.
3. **상태 동기화 필수 (State Synchronization)**: 루프가 종료될 때마다 반드시 [`STATE.md`](./STATE.md)를 최신화하여 컨텍스트 단절을 방지합니다.
4. **서킷 브레이커 준수**: 동일한 하네스 실패가 3회 연속 발생하면 작업을 중단하고 사용자에게 상황을 보고합니다.
